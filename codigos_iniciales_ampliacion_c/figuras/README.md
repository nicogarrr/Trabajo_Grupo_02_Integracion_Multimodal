# Capturas para la documentacion LaTeX

Guarda aqui las capturas con estos nombres para que `documentacion_practica_final.tex` las incluya automaticamente:

- `captura_dataset.png`: carpetas del dataset con las clases.
- `captura_captura_datos.png`: script de captura funcionando.
- `captura_colab_entrenamiento.png`: entrenamiento con MediaPipe Model Maker en Colab.
- `captura_vision_gestos.png`: canal visual reconociendo un gesto.
- `captura_chat_pln.png`: canal textual clasificando una frase.
- `captura_integrador_fusion.png`: integrador mostrando una fusion valida.
- `captura_clip_ventana.png`: ventana CLIP con rectangulo de mano.
- `captura_clip_logs.png`: logs de CLIP e integrador con la ampliacion.
- `captura_voz_asr.png`: canal de voz ASR transcribiendo una frase y fusionandose con un gesto previo.

Si una captura no existe, el PDF mostrara un recuadro de "Captura pendiente".
